## Описание
Реализация метрических методов бинарной классификации для предсказания `isAlive` на датасете Game of Thrones.
Выполнены части 1–5, 7–8. Часть 6 (Annoy) пропущена.

## Структура
- `config.py` — параметры варианта.
- `data.py` — загрузка и предобработка.
- `metrics.py` — метрики расстояния.
- `knn.py` — собственный kNN и LOO.
- `parzen.py` — окно Парзена (фиксированное и переменное).
- `potential.py` — метод потенциальных функций.
- `compactness.py` — профиль компактности и отбор эталонов.
- `logistic.py` — логистическая регрессия.
- `visualization.py` — графики.
- `main.py` — запуск всего пайплайна.
